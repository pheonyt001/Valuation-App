# Property Valuation Calculator

A mobile-first Nigerian Estate Management & Valuation calculator built with React, TypeScript, Vite and Tailwind CSS.

## Included calculators

- Y.P. in Perpetuity
- Y.P. Term Certain
- Present Value
- Annuity
- Deferred Annuity
- Sinking Fund
- Investment Method
- Term & Reversion
- Hardcore / Layer
- Leasehold
- Comparison Method
- Cost Method
- Depreciation
- Residual Method
- Development Appraisal
- DCF
- NPV
- IRR
- Profit Method
- Yield / Capitalisation
- Loan-to-Value
- Marriage Value
- Compensation

Also includes formula library, calculation history, study mode, dark mode, validation and print/PDF-friendly results.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```

## Test

```bash
npm test
```

## Deploy

The project can be deployed to Vercel, Netlify, Cloudflare Pages, GitHub Pages (with appropriate Vite base configuration), or any static host.

## Educational disclaimer

This calculator is intended for educational and preliminary estimation purposes. Property valuation depends on the property, market evidence, valuation date, assumptions, professional standards and applicable Nigerian laws. Calculations should not be treated as a substitute for a professional valuation report by a qualified Estate Surveyor and Valuer.
